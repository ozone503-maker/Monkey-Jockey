# Monkey Jockey UI palette lock

The interface must move away from the generic green-and-black treatment. Green belongs to the Punahēle environment; it is not the default menu color.

## Core colors

| Token | Hex | Primary use |
|---|---:|---|
| Juicy blue | `#2AA8FF` | Active controls, energy, selection accents |
| Basalt gray | `#4B5257` | Borders, neutral surfaces, disabled states |
| Fruity Puppy pink | `#E0517D` | Primary CTA, names, signature accent |
| Dark blue | `#102A5C` | Cards, HUD panels, title support |
| Plum purple | `#35163F` | Main page background and replacement for most black |

## Usage rules

- Replace most pure-black UI surfaces with plum purple.
- Use true black sparingly for shadows, outlines, and accessibility contrast.
- Use dark blue for readable structural panels.
- Use juicy blue and Fruity Puppy pink as the high-energy accents.
- Use basalt gray as the grounded volcanic neutral.
- Do not return the menus to rainforest green.

## Title lockup

Place `art/brand/monkey-face.png` beside the words **MONKEY JOCKEY**. The monkey face is part of the title identity, not a replaceable emoji or generic monkey icon.
